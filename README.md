## 电信、联通、移动分别怎么选

一句话版本：电信认准 CN2，联通优先看日本，移动别对普通线路抱太高期待。

| 你的宽带 | 优先考虑 | 尽量避开 |
| --- | --- | --- |
| 电信 | CN2 GIA-E、DC9 CN2 GIA | 普通线路的晚高峰 |
| 联通 | 日本机房（东京 / 大阪）、CN2 GIA-E | DC2 QNET |
| 移动 | CN2 GIA-E、DC9、香港 | 普通机房里的“精挑细选” |

**电信用户**是三家里最省心的，电信网络对 CN2 线路支持最好，DC3、DC8 这类带 CN2 的机房在电信宽带下表现都不差，差别主要在高峰期稳定性。预算够直接 DC9 或 CN2 GIA-E；预算有限，DC8（延迟大约 160–180ms）或 DC3 当折中选择可以，但别指望晚高峰。

**联通用户**有一个额外选项：日本机房。联通到日本方向的线路质量突出，速度表现甚至能和香港机房掰手腕，所以联通买 GIA-E 之后切日本机房是个经典玩法。反方向也要记住一条——DC2 QNET 在联通宽带下表现最差，能避就避。

**移动用户**比较尴尬，除了香港和 DC9，其他机房表现都差不多，没有特别突出的。预算允许就直接 CN2 GIA-E 或香港机房；预算有限的话，普通机房随便挑一个测，把期望值放低就行。

## 下单前怎么测试线路速度

每个机房都有官方测试 IP 和测试文件，下单前后各测一轮最稳妥。流程不复杂：先 ping 测试 IP 看延迟，用 traceroute 看路由走的是哪条线，再下载测试文件看实际速度。重点测晚高峰，白天快不代表晚上稳。买完发现不理想，就趁冷却期内切到测得更好的机房。

## 常见问题

**CN2 GIA-E 和 DC9 CN2 GIA 是什么关系？**
GIA-E 是套餐名，DC9 是机房名。买 CN2 GIA-E 套餐后可以在 14 个机房里切换，DC6、DC9 和日本软银都在其中；DC9 限量版则是锁定 DC9 机房的独立套餐，价格更低，配置也相应缩水。

**CN2 GT 套餐还能买吗？**
在退场。它曾经是很有性价比的折中线路，但按现在的选购逻辑已经不适合作为新用户的目标，价格表里保留只是为了对照。

**香港机房值不值得等补货？**
延迟确实最低（约 30–50ms），但 $899.99/年起步、长期缺货。对大多数场景，DC9 的 150ms 已经够用，非刚需不必等。

**大阪和东京两个日本机房怎么选？**
大阪 JPOS_6 带宽 1.5Gbps，2 核 2GB 年付 $499.99，可选机房有 19 个；东京 JPTYO_8 带宽 1.2Gbps，2 核 2GB 年付 $899.99。预算有限选大阪，对东京低延迟有执念再上东京。
